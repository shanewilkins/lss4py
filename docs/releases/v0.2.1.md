# v0.2.1 release notes — draft

Standalone sprint scope completed locally on 2026-10-27. This is a release-target
draft, not a publication announcement. Source and distribution metadata remain
0.2.0 as required by the sprint plan; selecting the release version, tagging,
uploading and updating the sibling book dependency are separate release steps.

## FLO-backed White Belt workflow

The [runnable book workflow](../flo-book-workflow.md) validates the actual book
model with published FLO 0.5.0, maps observed activities to stable node IDs,
derives baseline VA/RNVA/NVA classes from first-class FLO value classifications, reconstructs all 39 orders
and saves an audited bundle plus FLO's modeled value-stream SVG. Source hashes,
producer/model revisions, mapping, classifications and analyst conventions
survive restoration. Modeled durations do not enter observed arithmetic.

The result reproduces 3535.3 VA minutes / 25840.5 lead minutes, 13.7% PCE,
662.6-minute mean lead, 676.2-minute nearest-rank eligible P90, six deadline misses
among 21 eligible orders and five corrections affecting five orders. The CSV-only
route remains independently usable. FLO is optional; bridge operations on
portable exports remain available in the base installation.

## Explicit preparation boundaries

A bounded Pydantic pilot validates portable process/projection shapes with strict
types and identifiable error locations, preserving original canonical snapshots,
extensible producer metadata and 0.4.2/0.4.3 restoration and current 0.5.0 profiles. Pydantic is now declared
directly in core (`>=2.12,<3`). Domain dataclasses, numerical kernels and the
standalone standard-library bundle validator retain their existing approach.

Pint is a direct core dependency (`>=0.25,<1`) for the separate
`convert_duration_columns` API. Explicit seconds/minutes/hours conversions use a
private lazy registry, preserve backend and observation identity, and return
portable conversion evidence. The API does not infer clock semantics or convert
operating days/calendars; existing normalization and analytical unit behavior
remain unchanged. See [duration units](../duration-units.md) and ADR-0027.

## Toolchain and hardening

Ruff's C901, D and S rules replace Xenon/Radon, pydocstyle and Bandit;
Interrogate is removed. Locked local hooks, full-package coverage, stricter test
configuration, pinned Actions, workflow validation and retained test artifacts
make the source and installed-package checks reproducible. Release tooling can
test the exact wheel selected for publication.

Additional tests cover CLI diagnostics, structured logging, local telemetry
export, malformed evidence, plotting and CSV ingestion contracts. Full-package
statement coverage remains gated at 90% without exclusions. Deferred workflow
and Markdown-rendering stubs remain unimplemented; broader Pydantic migration,
branch-coverage gating and general unit/calendar support are outside this scope.

Final local evidence and limitations are recorded in the
[sprint acceptance assessment](../assessments/v021-sprint-acceptance.md).
