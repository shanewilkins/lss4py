# v0.2.0 release notes — draft

Unreleased candidate scope, assessed 2026-10-24. Package metadata is 0.2.0, shared by public exports and provenance.
The [acceptance follow-through](../assessments/v02-release-readiness.md) records
completed local corrections and pending official publication. These notes describe
the candidate; they are not an announcement that it is available on PyPI.

## Contract foundation

- Public analytical imports live at `lss4py`; private `_kernels` own calculation.
  Core ingestion materializes Polars; pandas is an optional input backend.
- `DataContract`, `ColumnRule`, `validate_data` and `normalize_data` provide explicit
  preparation, structured findings and opt-in normalization with retained evidence.
- `Specification` and `AnalysisWindow` declare CTQs, units, specification limits,
  opportunity definitions and analytical context.
- `get_analysis` and `get_candidates` expose thirteen registered calculations and discovery methods with
  prerequisites, assumptions and limits. Practitioners select and call methods.
- Typed descriptive, timing, funnel-yield, defect-yield, capability order reconstruction and process discovery
  results preserve calculation evidence. Audited v2 bundles link
  results, source bytes, software versions and specifications. Legacy v1 bundles
  remain readable; audit-context upgrades require explicit evidence.

## Measurements and book examples

`describe` adds explicit nearest-rank percentiles and `measurement_sum`, retaining
its linear percentile default and the meaning of `total` as observation count.
`deadline_performance` separates eligibility cutoff from a fixed readiness deadline.
Cohort PCE uses matched cases and a ratio of VA/lead sums.

Declared CSV adapters load all thirteen selected White Belt simulation sources.
`NumericLogContract` and `NumericEventLog` retain numeric operating clocks,
scoped case/load/activity/pass identities and source evidence. Numeric operating
times are not interpreted as calendar offsets by `lead_time`.

`reconstruct_orders` applies an explicit serial-path and parallel-envelope policy,
retaining source observations, per-record durations/classes, collapsed activity
passes and complete orders. All 39 Friday 91 orders match the independently pinned
prepared summary, including WNF-003. Five corrections affect five orders. The
standalone prepared preview and full reconstruction reproduce mean lead 662.6
minutes, eligible P90 676.2 minutes, six misses among 21 eligible orders, and
cohort PCE 13.7%.

`capability_indices` provides Cp/Cpk components, confidence intervals and governing
specification Z distance with an explicit sigma-shift assumption. `process_yield`
provides opportunity Yield/FTY/RTY/DPMO and optional actual DPU under declared
counting rules. Retained genuine R SixSigma cases pass; documented semantic and
invalid-domain differences prevent a claim of whole-package parity.

See the [migration guide](../migration-v0.2.md), [prepared preview](../book-preview.md)
and [reconstruction guide](../order-reconstruction.md) for executable examples.

## Contract corrections and compatibility limits

Older timing APIs now reject missing/nonfinite or negative operands before
arithmetic. `wait_time` declares its common unit, defaulting to hours. Exact binary
stage values are checked before conversion, and boolean options reject truthiness
coercion. Unsupported eager inputs remain TypeError-compatible while participating
in the LSS4PY exception hierarchy.

Row-wise timing accepts unique explicit scalar keys and retains source positions.
Detached result exports support Polars, pandas and Arrow. Per-result context records
semantic schema identity, missing policy, source selection and numerical/backend
versions; audited bundles check those versions. Explicit `AnalysisSelection`
records method choice without running a calculation. `map_process` returns a
portable typed result; legacy nodes/edges reads remain available.

A common ISO/native datetime parser fixes the Arrow timezone/fractional string
exception. Inputs have microsecond precision and consistent timezone awareness;
non-ISO text and numeric operating-clock coercion are unsupported. Removing unused
statsmodels makes pandas optional in a clean base installation.

Branch-aware interval wait/PCE, lifecycle pairing, OCEL interchange, general branch
reconstruction, full capability studies and later belt workflows remain outside
the delivered contract. Reconstruction is an implemented v0.3-owned slice delivered
early; this does not declare the Yellow Belt MVP complete.

The release workflow now requires quality/Arrow acceptance, locked Twine metadata
checks, source/project/tag identity agreement and installed-wheel ecosystem checks.
It then verifies the exact official package in a clean PyPI-only installation after
publication. The 0.2.0 candidate has not been published or tagged during this work.
The sibling book still needs that official release and a normal lockfile update.
